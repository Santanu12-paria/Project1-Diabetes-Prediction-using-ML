# Project1-Diabetes-Prediction-using-ML
## Overview

This Project predicts whether a patient is diabetic or not using Machine Learning.

## Problem Statement

Diabetes is a common disease that affects millions of people. Early prediction helps in better treatment.

## Dataset Features

* Pregnancies
* Glucose
* Blood Pressure
* Skin Thickness
* Insulin
* BMI
* Diabetes Pedigree Function
* Age

## Technologies Used

* Python
* Pandas
* Numpy
* Matplotlib
* Scikit-Learn
* Google Colab

## ML Algorithm Used

Support Vector Machine

## Workflow

1. Data Collection
2. Data Preprocessing
3. Train-Test Split
4. Model Training
5. Prediction
6. Evaluation

## Output

The model predicts:
 * Diabetic
 * Non-Diabetic
